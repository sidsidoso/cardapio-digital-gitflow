# Cardápio Digital

Projeto acadêmico para demonstrar o ciclo de desenvolvimento com Git, GitHub e GitFlow.

Abra `index.html` no navegador. Esta versão inicial contém apenas a estrutura da página.

O trabalho será organizado em `main`, `develop`, `feature/listar-produtos`, `release/1.0.0` e `hotfix/1.0.1`.
Os produtos e valores são fictícios; o projeto não recebe pedidos nem pagamentos.
