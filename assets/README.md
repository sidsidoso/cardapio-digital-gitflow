# Imagens do cardápio

Fotografias ilustrativas geradas por IA para a identidade fictícia Brasa.
Não representam produtos ou estabelecimento reais. Não exigem serviço externo para carregar.

- `hamburguer.png`: pão tostado, carne e queijo, fundo vinho.
- `batata.png`: batatas douradas em cesta com papel.
- `suco.png`: suco gelado e laranjas. A composição original também contém um hambúrguer;
  o enquadramento em CSS exibe a metade direita com o copo e as frutas.

Dimensões dos arquivos: 1536 × 1024 pixels. Textos alternativos ficam em `app.js`.
